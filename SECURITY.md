## Reporting a Vulnerability

We take the security of our open-source project seriously. If you discover a security vulnerability or potential risk within **Asteroids 2D**, please follow these reporting procedures:

### How to Report
1. **Do NOT open a public GitHub issue.**
2. Send a detailed report via email to **saad.mugen@gmail.com** or open a private security advisory report on GitHub.
3. Include the following details in your report:
   * Description of the vulnerability or security flaw.
   * Reproduction steps or proof-of-concept payload.
   * Potential impact on client execution or built executables.

### Response & Disclosure Timeline
* **Acknowledgement:** You will receive an initial acknowledgement of your report within **48 hours**.
* **Assessment:** The maintainers will evaluate the report and confirm the vulnerability within **5 business days**.
* **Patch Release:** If confirmed, a security patch will be prepared and released in a patch release (`v1.0.1+`) as soon as possible.
* **Public Disclosure:** Public disclosure will take place after a patch has been published.
